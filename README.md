# 📄 PDFR

**PDFR** è un visualizzatore di PDF semplice, leggero e moderno, sviluppato in Python utilizzando Qt6 (PySide6). 

È pensato per offrire un'interfaccia pulita e immediata per aprire e consultare i tuoi documenti PDF con funzioni essenziali di zoom e adattamento alla pagina.

---

## 🚀 Caratteristiche principali

* **Interfaccia intuitiva:** Barra degli strumenti pulita con accesso rapido ai comandi principali.
* **Gestione dello zoom:** Ingrandisci, rimpicciolisci o adatta la pagina alla larghezza della finestra con un solo clic.
* **Contatore pagine:** Visualizzazione immediata del numero totale di pagine del documento aperto.
* **Pronto all'uso:** Nessuna installazione di Python o librerie richiesta (disponibile come eseguibile standalone).

---

## 📥 Download e Utilizzo

Se desideri utilizzare subito l'applicazione senza configurare un ambiente di sviluppo:

1. Vai alla sezione **[Releases](../../releases)** di questo repository.
2. Scarica l'ultima versione dell'eseguibile (`PDFR.exe`).
3. Posiziona il file eseguibile insieme alla sua icona (`PDFR.ico`) nella stessa cartella.
4. Avvia `PDFR.exe` per iniziare ad usare l'applicazione!

---

## 🛠️ Tecnologie utilizzate
